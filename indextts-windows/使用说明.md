# IndexTTS 2.5 Windows 一键安装

适用于：Windows 10/11 + NVIDIA 显卡（8 GB 显存可用），安装到 `D:\IndexTTS`。

## 安装步骤

1. 下载本文件夹里的 `install.bat` 和 `启动.bat`，放到同一个地方（比如桌面）。
2. 双击 `install.bat`。
   - 如果弹出蓝色的“Windows 已保护你的电脑”：点“更多信息” → “仍要运行”。
   - 全程大约下载 10 GB，可能要 30 分钟到 1 小时，期间不要关闭窗口。
   - 中途失败了直接重新运行，已完成的步骤会自动跳过。
3. 看到“安装完成”后，以后每次双击 `启动.bat` 即可，浏览器会自动打开 http://127.0.0.1:7860 。

## 脚本做了什么

| 步骤 | 内容 |
|---|---|
| 1 | 检查 NVIDIA 驱动（需要 570 以上版本，支持 CUDA 12.8） |
| 2 | 下载 uv 到 `D:\IndexTTS\uv`，不改系统环境变量 |
| 3 | 从 GitHub 官方仓库下载代码（失败自动走 ghfast 镜像） |
| 4 | 安装 Python 3.11、PyTorch(CUDA 12.8) 和网页界面依赖，PyPI 用阿里云镜像 |
| 5 | 从 ModelScope 下载 IndexTTS-2.5 模型 |

所有文件都在 `D:\IndexTTS` 里，不占 C 盘。卸载时直接删除这个文件夹即可。

## 8 GB 显存说明

程序检测到显存小于 10 GB 时会自动：

- 使用半精度推理（省显存，音质几乎不变）；
- 长文本自动分段合成；
- **不加载“根据文字描述情感”的模型**，所以“用文本描述情感”这项用不了；用参考音频或情感滑块控制情感都正常。

## 常见问题

- **报 CUDA 相关错误**：更新 NVIDIA 驱动到最新版。
- **下载很慢或断开**：换个网络，或者重新运行 `install.bat` 继续。
- **其它报错**：把黑色窗口里的报错截图发给 Claude。

模型使用遵循 bilibili 模型使用协议，商用需联系 indexspeech@bilibili.com。
